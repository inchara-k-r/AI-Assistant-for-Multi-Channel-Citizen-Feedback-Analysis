# AI Assistant for Multi-Channel Citizen Feedback Analysis in Public Services

## Overview

This project develops an AI-powered assistant that automatically analyzes citizen feedback collected from multiple communication channels such as social media, emails, messaging platforms, and government portals.

The system applies Natural Language Processing (NLP) and Machine Learning techniques to classify complaints, analyze sentiment, detect urgent issues, generate summaries, and visualize insights through an interactive dashboard.

---

## Features

- Multi-channel feedback collection
- Text preprocessing
- Complaint category classification
- Sentiment analysis
- Urgency detection
- Automatic summarization
- Interactive analytics dashboard
